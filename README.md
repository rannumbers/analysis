# Ran The Numbers: the maths behind each video

Each Short answers one question people ask about their own money or odds,
by running it thousands of times and checking the result against the exact
maths. This repo holds the simulation code and, for each video, the method,
the assumptions and every number shown on screen.

| Video | The question |
| --- | --- |
| [01-random-walkers](videos/01-random-walkers/README.md) | Is someone with a brilliant investing record actually skilled? |
| [01b-stock-pickers](videos/01b-stock-pickers/README.md) | Should I pick my own stocks, or buy the top 100? |
| [04-rebalancing](videos/04-rebalancing/README.md) | Should I reset my mix of shares and cash every year, or leave it alone? |
| [05-card-set](videos/05-card-set/README.md) | Should I keep opening packs to finish my set? |
| [06-drunk-bird](videos/06-drunk-bird/README.md) | I'm lost. Should I keep walking, or stay put? |
| [07-kelly](videos/07-kelly/README.md) | You've got an edge. How much should you bet each time? |
| [08-sequence-risk](videos/08-sequence-risk/README.md) | I'm about to retire. Does it matter when the bad years come? |
| [09-house-edge](videos/09-house-edge/README.md) | I've got $100 at the casino. Can I double it? |
| [10-doubling-down](videos/10-doubling-down/README.md) | My mate says doubling after every loss means you can't lose. Does it work? |
| [11-benford](videos/11-benford/README.md) | If someone made up the numbers on an expense claim, would an auditor notice? |
| [12-shuffles](videos/12-shuffles/README.md) | How many times should I shuffle before a game of cards? |
| [13-streaks](videos/13-streaks/README.md) | My mate won six in a row. Is he on a hot streak, or is it just luck? |
| [14-buffon-needle](videos/14-buffon-needle/README.md) | Could I work out pi by dropping matches on my floorboards? |
| [15-start-earlier](videos/15-start-earlier/README.md) | Is starting to invest ten years earlier really worth it? |
| [16-lump-sum](videos/16-lump-sum/README.md) | I've got $60,000 to invest. Do I put it all in now, or spread it over a year? |
| [17-rentvest](videos/17-rentvest/README.md) | Should I buy a home with a mortgage, or rent and invest the difference? |

## Run everything

```bash
npm install
npm test
```

Assumptions are illustrative. General information only, not financial advice.
